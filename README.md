Meritt North Catalogue

## Go Live (GitHub Pages)

This project is a static site (`index.html`), so the fastest way to go live is GitHub Pages.

1. In GitHub, open **Settings → Pages** for this repository.
2. Under **Build and deployment**:
   - Set **Source** to **Deploy from a branch**
   - Set **Branch** to **main** (or your default branch)
   - Set **Folder** to **/** (root)
3. Click **Save** and wait 1–3 minutes for the first deployment.
4. Open the live URL shown in the Pages settings and test key flows.
5. (Optional) Add a custom domain in Pages settings, then update DNS records to point to GitHub Pages.
